# UNDERCURRENT — Design Language

---

## 1. ポジショニング

> 洗練されているが閉鎖的ではない
> 上質だが、古典的Luxuryではない
> 知的だが、勉強臭くない
> Socialだが、SNS的に騒がしくない

これを視覚に翻訳すると:

| 避ける | 採る |
|---|---|
| 黒地 × 金の高級レストランUI | 紙のような温白色 × 深いインク |
| 大きな料理写真のヒーロー | タイポグラフィと余白のヒーロー |
| 丸いアバターとフォロワー数 | 名前と日付の組版 |
| グラデーションボタン、影、角丸大 | 罫線、1px、直角に近い角 |
| アイコン中心のナビ | 語彙中心のナビ |
| 派手なマイクロインタラクション | ほぼ静止。動くのは滲みだけ |

**参照すべき視覚言語は、レストランのWebサイトではなく、
展覧会カタログ・学術紀要・古い株式登記簿・種苗のカタログ。**

---

## 2. カラー

抽出（低温・減圧）と植物から取る。彩度は全体に低い。

```css
--paper      #F4F1EC   /* 地。白ではなく、わずかに温かい紙 */
--paper-2    #EBE7E0   /* 面の切り替え */
--ink        #15171A   /* 文字。純黒にしない */
--ink-70     #4C5054
--ink-45     #82868B
--line       rgba(21,23,26,.14)

--cold       #1C4A50   /* 主アクセント。低温抽出の深い青緑 */
--cold-2     #2E6F73
--leaf       #5C6B3E   /* 植物 */
--ember      #A2472C   /* 警告・強調。極めて限定的に */
```

**アクセントは面で使わない。線と小さな文字で使う。**
ボタンの塗りは `--ink`、アクセントは罫線とラベルにだけ現れる。

---

## 3. タイポグラフィ

Webフォントの外部読み込みをしない（プロトタイプがオフラインでも壊れないため、
かつ日本語の明朝が環境に既にあるため）。

```css
--serif: ui-serif, "Hiragino Mincho ProN", "Yu Mincho", "Songti SC", Georgia, serif;
--sans:  ui-sans-serif, -apple-system, "Hiragino Sans", "Yu Gothic", "Noto Sans JP", sans-serif;
--mono:  ui-monospace, "SFMono-Regular", Menlo, monospace;
```

役割:

| 用途 | 書体 | 特徴 |
|---|---|---|
| Creator名、見出し、思想の一文 | **serif** | 明朝。日本語環境で最も「文化」に見える |
| UI、本文、説明 | **sans** | 読ませる |
| 数値、日付、番号、記録 | **mono** | ★ Registerの説得力はここで決まる。数字は等幅で |

`Founding Supporter No. 007` `Supporting since 2026.03` `43` は**必ず mono**。
等幅数字は「集計された事実」に見える。プロポーショナルだと「デザインされた宣伝文句」に見える。

ラベルは小さく、字間を開け、大文字。
```css
.label { font-size: 11px; letter-spacing: .16em; text-transform: uppercase; }
```

## 4. Taste Signature（生成図形）

**写真を使わない代わりの視覚アイデンティティ。**

各Creatorは5軸のTaste Profile（Aroma / Acidity / Bitterness / Sweetness / Finish）を持ち、
そこから決定論的に有機的な図形を生成する。

- 5軸の値を半径にした閉曲線を、seedベースのゆらぎで3〜4枚重ねる
- 低い不透明度、乗算的な重なり。にじみ・抽出の連想
- 同じCreatorは常に同じ図形（決定論的）
- Consumer自身もTaste Signatureを持つ → Creatorとの重なりが「相性」の表現になる

これにより:
- 実在しない人物の偽の顔写真を作らずに済む
- ストックフォトの既視感を回避する
- 「Tasteは目に見えないものである」というテーマ自体を視覚化する

---

## 5. モーション

原則: **ほぼ動かさない。**

- 許可: `opacity` と `transform: translateY(4px)` 程度の、200〜400msの入場
- 禁止: バウンス、スケール演出、紙吹雪、カウントアップアニメーション、達成モーダル
- 数字をカウントアップさせない。**記録は最初からそこにあったように出す**

---

## 6. レイアウト

- 最大幅 `1120px`。本文カラムは `640px` を超えない
- 罫線（1px `--line`）で区切る。カードの影を使わない
- 余白は大胆に。セクション間は `96–140px`
- グリッドは12カラムだが、意図的に非対称に置く（左寄せの見出し＋右のずれた本文）

---

## 7. 禁止事項（再掲・実装レベル）

```
❌ プログレスバー / レベルバー
❌ ポイント・スタンプ・XP・バッジアイコン
❌ 「あと◯回でPatron」
❌ 金額ランキング / 順位番号
❌ 星評価 / スコア
❌ 「残り◯回」の大きな表示
❌ 紙吹雪・効果音・達成モーダル
❌ 丸アイコン + フォロワー数の並び
❌ COLDRAWの機械のヒーロー画像
❌ カウントダウンタイマー
```

---

*Creator名・数値・履歴はすべて架空のプロトタイプ用データです。*
