# 🏪 石井ショップ

**家にある不用品を、スマホのカメラで撮るだけ。** AIが商品情報を自動で作成し、そのまま出品・販売できるフリマ風アプリです。

写真を撮る（または動画を撮る）だけで、OpenAI の画像認識が

- 商品タイトル
- 商品説明
- カテゴリ / ブランド推定
- 状態
- おすすめ販売価格（と、その理由）
- 検索タグ

を自動生成します。あとは内容を確認して「出品する」を押すだけ。

## 使い方（アプリの流れ）

1. **出品する** タブでスマホのカメラを起動し、不用品を撮影
   - 写真は複数枚OK（最大4枚）
   - 動画を撮ると、代表フレームを自動で抜き出して解析します
2. 「✨ AIにおまかせで商品情報をつくる」をタップ
3. AIが作った商品情報を確認・微調整
4. 「この内容で出品する」でショップに並びます
5. **ショップ** タブで一覧・詳細・購入（モック）ができます

## セットアップ

```bash
npm install
```

`.env` に OpenAI の APIキーを設定します（未設定でもデモ用のモックデータで動きます）。

```bash
# .env
OPENAI_API_KEY=sk-...
# 任意: 画像認識に使うモデル（既定: gpt-4o-mini）
OPENAI_VISION_MODEL=gpt-4o-mini
# 任意: ポート（既定: 3000）
PORT=3000
```

起動:

```bash
npm start
```

ブラウザ（スマホ推奨）で `http://localhost:3000` を開きます。

> 📱 スマホのカメラ機能は `https` もしくは `localhost` でのみ動作します。実機で試す場合は ngrok などのトンネルを利用してください。

## API

| メソッド | パス | 説明 |
|---|---|---|
| `POST` | `/api/analyze` | 画像(data URL配列)を解析して商品情報を生成 |
| `POST` | `/api/items` | 商品を出品（画像を保存して登録） |
| `GET`  | `/api/items` | 商品一覧 |
| `GET`  | `/api/items/:id` | 商品詳細 |
| `POST` | `/api/items/:id/buy` | 購入（モック：売り切れにする） |
| `DELETE` | `/api/items/:id` | 出品を削除 |
| `GET`  | `/health` | 稼働確認 / AI有効状態 |

## 技術メモ

- **バックエンド**: Node.js + Express（ES Modules）
- **AI**: OpenAI Chat Completions（Vision対応モデル）。`lib/ai.js`
- **保存**: `data/items.json` と `data/uploads/`（軽量なファイルベース。`data/` は Git 管理外）
- **フロントエンド**: 依存なしのバニラJS。スマホファーストのUI
- **動画対応**: サーバー側の ffmpeg 等に依存せず、ブラウザ側で動画から静止画フレームを抽出して解析します
